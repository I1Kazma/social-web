<h2>Overview</h2>
<p>social-web is an open-source social media platform built with React and Node.js, offering a rich set of features for creating engaging social applications. It combines a modular frontend architecture with a scalable backend, enabling seamless user interactions and content sharing.</p>
<p><strong>Why social-web?</strong></p>
<p>This project empowers developers to build, extend, and customize social networking apps with ease. The core features include:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0">🎨 <strong>🧩 Modular Components:</strong> Reusable UI elements like feed, posts, sidebar, and profile for flexible development.</li>
<li class="my-0">🚀 <strong>⚙️ API Integration:</strong> Robust backend with user, post, and auth routes supporting dynamic data flow.</li>
<li class="my-0">🔐 <strong>🔑 Authentication &amp; User Management:</strong> Secure login, registration, and real-time profile updates.</li>
<li class="my-0">🎯 <strong>🖌️ Maintainable Styling:</strong> Styled with Sass and CSS maps for scalable, organized design.</li>
<li class="my-0">💬 <strong>🌐 Social Interactions:</strong> Features like likes, comments, follow/unfollow foster engaging user experiences.</li>
</ul>

<h2>Getting Started</h2>
<h3>Prerequisites</h3>
<p>This project requires the following dependencies:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0"><strong>Programming Language:</strong> JavaScript</li>
<li class="my-0"><strong>Package Manager:</strong> Npm</li>
</ul>
<h3>Installation</h3>
<p>Build social-web from the source and install dependencies:</p>
<ol>
<li class="my-0">
<p><strong>Clone the repository:</strong></p>
<pre><code class="language-sh">❯ git clone https://github.com/I1Kazma/social-web
</code></pre>
</li>
<li class="my-0">
<p><strong>Navigate to the project directory:</strong></p>
<pre><code class="language-sh">❯ cd social-web
</code></pre>
</li>
<li class="my-0">
<p><strong>Install the dependencies:</strong></p>
</li>
</ol>
<p><strong>Using <a href="https://www.npmjs.com/">npm</a>:</strong></p>
<pre><code class="language-sh">❯ npm install
</code></pre>
<h3>Usage</h3>
<p>Run the project with:</p>
<p><strong>Using <a href="https://www.npmjs.com/">npm</a>:</strong></p>
<pre><code class="language-sh">npm start
</code></pre>
